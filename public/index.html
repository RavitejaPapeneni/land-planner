🌱 Land Planner

Free permaculture site report for any place on Earth. Built only from open data — every number comes from an API or a shown formula.

Or click the map to drop a pin.

Data sources

  • Geocoding: OpenStreetMap Nominatim (© OpenStreetMap contributors, ODbL)
  • Map tiles: OpenStreetMap via Leaflet
  • Climate: Open-Meteo Historical Weather API (ERA5, last full calendar year, CC BY 4.0)
  • Elevation & slope: Open-Meteo Elevation API (Copernicus DEM 90 m)
  • Soil: ISRIC SoilGrids v2.0 (0–30 cm, CC BY 4.0)
  • Species: GBIF occurrence API (records within ~10 km; recorded nearby, not guaranteed native)
  • Sun path: NOAA-style solar position formula computed in your browser.
  • Plant list, calendar, house notes: built-in general guidance by climate type (Köppen-style rules from the climate data). Check locally.
